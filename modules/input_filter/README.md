# 模型输入屏蔽

在 QQ 消息进入 AstrBot 处理管道之前，复用当前配置中的 `content_safety.internal_keywords.extra_keywords` 规则检查正文、相邻文字段和已解析的引用文字。命中后整条停止，不调用模型、不排队绘图、不交给学习采集或艾特判断；群聊、私聊和管理员一视同仁。

词表仍在 AstrBot 的“配置 → 内容安全 → 内部关键词 → 额外关键词”维护，不向模型注入词表。关闭本插件开关可关闭前置拦截，原框架内容安全设置保持有效；卸载或重载时恢复原处理入口。原来的输出禁词替换插件保持独立。

这是文本输入筛选，不识别图片中文字、音频或视频内容；不删除旧聊天记录及已有记忆。原始 QQ 消息仍可能由框架写入本机日志。
