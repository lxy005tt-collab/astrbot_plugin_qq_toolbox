# 先检索资料和参考图，再绘图

在「OpenAI 画图」插件设置开启“绘图前联网检索资料和参考图”。同一中转站的 `gpt-5.6-sol` 通过 Responses `web_search` 检索文字资料及参考图；最终图片仍由原来的 `gpt-image-2.5-sunburst` 绘制。

下载成功的联网参考图会实际上传至图生图接口，检索摘要作为补充资料附在原始绘图要求之后。若参考图无法下载，则使用已经搜索到的文字资料；若搜索本身未完成或未返回可核对来源，则停止此次任务，不调用生图、不扣次数。图片下载仅接受公开 HTTP(S) 地址和经过校验的 PNG、JPEG、WebP。

兼容中转站的 SSE 流式返回。若实际搜索已经完成，后续文字摘要遇到上游繁忙或中断，会保留搜索结果：使用已下载的参考图、真实检索片段，或读取已返回来源的网页摘录。只有来源链接而没有任何可用图像或文字时仍停止绘图。上游拒绝、权限错误不走恢复路径。固定人物与遮罩编辑仅请求文字检索，避免无用的图片搜索。

开启“联网检索故障时启用备用搜索”后，第一次中转站临时错误会转到独立的 Bing 公开网页检索，并按需查询真实图片结果；使用实际返回的摘要及下载校验后的参考图，不用模型编造检索资料，不需要新的 API Key。固定人物仍只补充文字，原始设定图和用户原图优先。备用搜索不可用时再重试一次中转站；两条通道都失败才停止绘图并归还额度。查询词会交给 Bing 搜索，原中转站密钥不发送到外部网站。每个任务的检索日志包含独立 request 标识，方便区分群内同时发起的多个绘图任务。

普通文生图、自然语言工具、图生图/修图及人物工具共用此流程。带原图的编辑保留原图在前；使用遮罩或 mimi 固定人物参考图时只补充检索资料，不增加外部图片，避免更换人物身份或遮罩对象。mimi 人物插件原有启停状态不会随此功能改变。

按用户要求，QQ群中成功绘图只发送成图：不发送检索过程、网页资料、来源链接、搜索得到的参考图或“正在生成”等文字。背景任务发图独立于当前对话结果；只对成功提交了绘图任务的当前群消息抑制额外模型回复和表情。额度不足及失败提示照常保留。普通聊天和私聊输出规则不受此开关影响。

默认每次最多下载 2 张参考图。检索会额外产生文本模型/搜索工具用量，及检索和下载耗时。每日额度仍在开始检索前预占，整个“搜索 + 生图 + 发送”任务成功后只计 1 次，失败归还。
