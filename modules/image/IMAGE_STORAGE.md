# 绘图图片统一保存

绘图插件使用的图片统一保存在 AstrBot 数据目录下的 `绘图图片/`，当前安装位置是 `D:\Tools\AstrBot\data\绘图图片`。所有图片直接位于同一个文件夹，不再为联网图片创建子目录。

- `生成_`：生图接口返回的成图，包括 Base64 和 URL 下载。
- `联网_`：联网检索并下载的参考图。
- `群友_`：实际提交给图生图/修图接口的群友图片及遮罩，保持原文件字节，相同内容重复使用时复用归档文件。
- `设定_`：奶蛙、大肥鱼等固定人物的参考图。

平台自己的消息图片临时缓存保留，避免破坏聊天记录或其他插件的引用。普通群聊表情包不额外归档。统一目录不会按天自动清理；删除图片前需避开正在生成的任务，并保留仍在配置中使用的固定人物设定图。
