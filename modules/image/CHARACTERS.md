# 奶蛙 / 大肥鱼

- `/奶蛙 在海边弹吉他`：按黄色奶蛙设定图创作。
- `/大肥鱼 在咖啡店看书`：按蓝色女仆设定图创作。
- 同条消息附图并发 `/奶蛙` 或 `/大肥鱼`：模型识别主图的主要人物/角色/动物，用固定角色替换其完整形象，尽量保留姿态、构图、背景和原图画风。
- 附图时可以加要求，例如 `/奶蛙 替换左边的人，保留右边的人`。
- 没有图片也没有提示词：提醒补充，不调用生图、不占额度。

支持同条消息中可解析到图片内容的引用回复。多张输入图时取首张为要修改的主图，不使用之前暂存的旧图。

固定设定图保存在插件数据目录 `character_templates/`，对应路径可在插件设置修改。图生图请求实际上传 `[原图, 固定设定图]`，无原图时上传 `[固定设定图]`；不靠名字让模型猜形象，也不把多角度设定图当成最终排版。

带图但无补充提示词时直接根据原图识别和替换，不另查互联网。补充了场景等提示词时复用当前资料检索开关，仅检索文字资料，不添加网上的人物图替代固定身份参考。

共用现有每日额度、并发限制和失败退款。QQ群中成功时只发成图，不发主体分析、固定设定图或参考资料。普通群友可用；管理员豁免沿用既有设置。
# 群聊文字提及兼容

群友可直接发 `/大肥鱼 提示词`、`/奶蛙 提示词`；真实 QQ 艾特后接指令照常支持。也兼容截图中的普通文字 `@mimi /大肥鱼 提示词`，先识别明确的绘图指令，再走原生权限、输入保护和额度流程，不会把普通聊天、未知指令或艾特别人的消息当成绘图任务。
