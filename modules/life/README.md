# 真实生活

为 Bot 的角色设置可连续参考的大学生日常。独立判断模型先根据北京时间、本地课表作息、本轮消息及可调的最近聊天，选择本轮需要提供的资料。

日程判断使用单独选择的 Provider，在插件设置中选择本机已配置的模型即可，不改变聊天主模型。

判断模型只返回“是否需要”以及“当前状态、某天课程、某天作息、一周课表”等资料范围。插件验证选择结果，再直接从本地课表读取事实，不采用判断模型生成的生活描述。无关话题不注入日程。

判断模型不接收人格、主聊天系统提示、工具结果、图片或群聊附加上下文。当前文本来自消息事件，不复制可能包含整个群聊窗口的 `req.prompt`；私聊连发合并启用时，当前文本是合并后的本轮消息。

“参考最近聊天条数”默认 **5**，可在 **0–20** 之间调整。0 只传本轮消息，不传聊天历史；其余设置只选当前会话的用户和助手聊天正文，每条最多 1200 字符，本轮消息最多 4000 字符。截断只影响独立判断输入，不修改主聊天消息。

独立判断每轮增加一次模型请求，日程、规则和选中的历史仍有 token 开销。默认超时 30 秒；失败、超时或返回无效结果时，只提供简短当前状态，不改用其他判断模型。主模型仍保留 `get_real_life_schedule` 本地查询工具，补充需要的其他时段。

## 默认安排

课程使用用户提供的地理学专业一周课表。周三两节 GIS 实验之间保留 15:40–16:00 的课间；周六、周日及其余未排课时段均无课。

普通作息是可修改的初始设定：23:00–07:00 睡觉，白天安排早餐、午饭、午休、晚饭及自由活动，19:00–21:00 自习，21:00 后放松及洗漱。课程覆盖同一时间段的普通活动。

这是角色的生活背景，不是实际定位或真人行踪。上课和睡觉期间也能正常聊天。插件不主动发消息。

聊天模型可以在不违反给定人设、课表作息、时间地点、已经明确的经历和约定的情况下，编造合理的虚拟生活细节和经历，例如餐食、课堂小事、日常见闻与感受。新补充的内容需要前后连贯，被追问时继续具体补充；不能推翻已有经历，也不能把别人说的事情认领为自己的经历。普通作息是背景时段，不要求整个时段每一分钟都持续同一动作，固定课程和明确约定仍按给定时间执行。

正常选择日程和判断失败的备用注入共用同一生活表达规则；空间日记和主动文案也沿用该规则。日程选择器仍只选择已有资料，不负责改写课表。真实生图、发消息等工具结果依实际回执确认。

## 使用

- 聊天时问“你现在在干嘛”“今天下午有课吗”“周三上什么课”。
- 在 AstrBot 插件配置的“真实生活”中修改课表、作息或私聊/群聊开关。
- “独立日程判断”中可选择判断模型、调整历史条数和超时。关闭独立判断后，恢复每轮提供简短当前状态。
- 课表默认按普通教学周重复，不自动推断节假日和学校调课。放假时可关闭“启用固定课程”，保留普通作息。

## 编辑格式

一行一个时段：`周一 08:00-09:40 自然地理学 | 教室`。

星期可用 `每天`、`工作日`、`周末`、`周一` 至 `周日`。地点可省略。支持跨午夜，如 `每天 23:00-07:00 睡觉 | 宿舍`；结束时间可写 `24:00`。

区间包含开始、不包含结束，例如 09:40 时已下第一节课。同一课表或同一作息内不能重叠；课表与作息可以重叠，优先上课。空缺的作息时间显示“自由安排”。

动态背景通过 AstrBot 官方的 `extra_user_content_parts` 临时注入，并标记 `mark_as_temp()`；不改写用户消息、人格或保存的会话历史。

插件不添加聊天指令。独立判断是否选对范围、聊天模型是否按日程回答，仍需通过实际对话观察。
