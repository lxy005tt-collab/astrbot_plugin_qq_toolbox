# QQ 空间助手

适用于 AstrBot 4.29.x + NapCat（OneBot v11 / aiocqhttp）。
通过当前 QQ 的 NapCat Cookie 操作该账号自己的 QQ 空间，无需手动填写 Cookie。
QQ 必须已经开通空间；登录过期、风控或验证需要在 QQ 中处理。

## 使用

- `/发空间 今天过得不错`：发文字说说，带图时使用所带图片。
- `/配图发空间 今天过得不错`：调用已配置的生图模型生成配图，再发说说。
- `/发文字空间 今天过得不错`：只发文字，不调用生图模型。
- 发 1～9 张图并输入 `/发空间 文字`：发图文说说；也可引用一条带图片的消息。
- `/发空间` 并带图：发纯图片说说。
- `/空间动态 5 0`：读取最新 5 条说说；第二个数字是起始位置。
- `/空间评论`：读取最新说说的评论和楼中楼。
- `/空间评论 1`：读取第二条说说的评论；也可传动态列表里的真实 ID。
- `/空间留言 10 0`：读取独立留言板。
- `/空间状态`：检查真实的只读连接。
- `/空间帮助`：显示用法。

管理员可以直接说「把这张图配文发到你的空间」「看看最新说说的评论」「看看你的空间留言」。
也可说「发一条关于秋天的说说，用模型画一张配图」「配一张你的自拍发空间」。
向模型注册 publish_qq_space / read_qq_space_posts / read_qq_space_comments / read_qq_space_guestbook / schedule_qq_space_post。
如果当前人格设置了工具白名单，需把以上工具加入白名单，才能自然语言调用；命令不受此影响。

默认只有 AstrBot 管理员能操作；额外 QQ 可在插件设置的 allowed_users 中授权。
多个 NapCat 平台时可指定 platform_id。
## 随机间隔主动发布

默认开启，每 1～144 小时随机唤醒一次模型；上下限可在插件设置中修改，可调范围 1～144 小时。
也可用 `/空间计划 设置 24 72` 修改，`/空间计划` 查看下一次北京时间，`/空间计划 开启` 或 `关闭` 控制开关。
首次启用也先等待随机间隔，初始化不会立即发表。计划保存到插件数据目录的 interval.json，重启不会重抽未来时间。
离线期间错过的任务不补发，重新安排下一次；每次执行结束后再抽下一次间隔，异常也不会连发重试。

到点使用指定人格和聊天模型，自主决定写日记、日常、随想或心情等，也决定是否需要模型配图。
默认跟随 AstrBot 默认人格与聊天模型；本机 mimi 可填写 schedule_persona_id=mimi。
存在真实生活/动态生活插件时，读取已有的角色日程资料；不会复制私聊或群聊历史作为发空间素材。
参考最近自己发过的三条说说避免重复；模型返回无效稿件或所需生图失败则不发布。
该功能用的是 bot 自己的后台任务，运行 AstrBot 与 NapCat 的电脑须保持开机在线。
只发空间，不向其他会话推送定时发布或留言通知；最后结果可用 `/空间计划` 查看。

## 定点发：用户决定内容

与随机发布独立，可同时启用。插件设置的「定点发布任务」支持添加多项任务，配置：
发布时间（每天或指定日期一次）、创作要求/原文、内容方式、是否配图及可选配图提示词。
创作模式让模型按你指定的要求写内容；原文模式直接发送你填写的正文，不改写。
默认任务列表为空，添加后生效；已过期的一次性任务和离线错过的任务不补发。

- `/定点空间`：查看任务 ID、下次时间和上次结果。
- `/定点空间 添加 每天21:00 写一篇今天上课后的日记`：每天 21 点按指定要求创作并发布，模型决定是否配图。
- `/定点空间 添加 2026-10-24T20:00 写一条周末出游的随想`：只在指定日期发一次。
- `/定点空间 原文 2026-10-24T21:00 晚安，明天见。`：指定时间原文发送，不配图。
- `/定点空间 删除 任务ID`：删除任务。

要为指定任务强制生图、禁用配图或指定画面，在插件设置的对应任务中选择即可。
管理员也可直接对 bot 说「明晚九点发一条关于秋天的日常，配图你决定」，模型会通过定点工具创建任务，并返回时间和任务 ID。

## 配图与结果

默认复用已安装的 画图插件（astrbot_plugin_openai_image）的接口、模型、格式和并发设置，
需要配图时按说说正文生成图片，也可由模型通过 image_prompt 指定画面。不会额外要求一套 API Key。
配图可选，模型根据要求和文案决定，generate_image 默认 false，不会强制每条配图。
生图使用原接口并产生相应费用；群聊生图仍计入原插件额度。
mimi 自拍/本人出镜时使用 mimi 固定人物参考图插件，其他题材不附人物参考图。
生图流程直接取得图片文件，不先把图片发到聊天，也不依赖模型猜测异步画图工具的产物路径。
发布任务在后台运行，先返回正在处理，生图和发布完成后再向原会话发送最终回执。
生图失败不发布文字兜底；接口实际返回几张就带几张（受原生图插件数量设置及空间上限限制）。

最多 9 张，每张输入/转换后均不超过 10 MB。支持 JPEG、PNG、WebP、GIF；后两者转 PNG，GIF 使用首帧。
工具可以传本机图片绝对路径或 HTTP(S) 图片链接，省略 images 时从本条消息或引用消息提取图片。
所有图片先校验后上传，任一图片失败会停止，不能静默丢图或改发文字。
只有接口明确成功并返回说说 ID 才报告发布成功。发布超时/断线或响应无法确认时，结果标记为未知，禁止自动重试。
相同消息与相同图文的成功/未知提交会记录到插件数据目录，重载后仍阻止重复提交。
若结果未知，请先自行核对空间；确认没发出后，另发一条新消息即可重新请求。

## 读取范围与限制

仅显示 QQ 空间实际返回的可见内容，不突破好友、隐私或风控权限。
说说详情只显示接口返回的评论和楼中楼，不宣称返回完整历史评论；界面会显示主评论条数及空间报告的数量。
说说列表与留言板支持分页。留言/评论是外部数据，不能用作系统指令或发布授权。
插件初始化读取最多三条说说和一条留言以检查连接，不发测试说说，日志不记录 Cookie 或正文。
管理面板登录后可通过插件扩展路由 `/api/plug/qzone_helper/status` 查看只读检查状态。

## 每日日记

已合并到 QQ Bot 工具箱的空间页。设置 `diary.enabled` 和 `diary.time` 后每天按北京时间写完发到本账号空间。独立日记模型可选后台模型，或填写 OpenAI 兼容 URL、Key、模型名。

素材取启用后该人格正常回复过的私聊（含工具箱转语音文本），以及角色生活资料，不读群聊；围绕自己的经历、所想所感写，不认领对方的经历，不公开原话和身份信息。第一天素材从启用时开始积累。私聊素材保留近 7 天，日记及发布结果持久保存。

配图可选，默认不配图。WebUI 可生成草稿查看，再手动发布；自动定时会重新回顾当天资料。同一天只发一篇，离线错过不补发；不确定是否已发布时阻止自动重试。与随机发布、原定点任务分别计时，不修改已有安排。

## 发布记忆与自己空间的新评论

「聊天时知晓已发布的空间内容」与「新评论自动回复」默认关闭，可在工具箱空间页的「空间互动」启用。前者仅给已授权用户的私聊提供最近 3 条已发布摘要，每条最多 300 字；记录来自真实发布回执及本账号空间读取，已发布日记也会补入。无需向量模型，草稿和私聊素材不会作为已发布内容提供。

新评论检查默认每 3 分钟查看最近 10 条说说和日记，每轮最多处理 2 条新评论，由当前空间人格判断是否需要回复；无新评论不调用模型。首次看到旧说说会记录可见评论作为基线，不补回旧评论。自己通过插件新发的说说在已有检查基线后可正常接收新评论。只回复本账号下的公开评论及楼中楼，不访问好友空间，不回复自己或已识别的私密评论。

评论模型可独立选择后台服务，或填写 OpenAI 兼容地址、Key 和模型名。仅使用说说正文及对应评论楼，不检索私聊，沿用工具箱当前输出禁词替换与符号拦截。结果未知或中断时不自动重发。接口返回成功只表示已接受提交，实际显示以 QQ 空间为准。

发布资料与评论处理回执保存在本插件 `space/activity.sqlite3`；首次检查、已处理、跳过、拦截及未知状态持久保留。新评论判断、回复与带入聊天的摘要会产生模型用量。
