# 输出禁词替换

QQ 消息发出前，由程序按你填写的对应关系替换文字。不向模型添加提示词，不调用模型判断，也不增加模型请求。

## 配置

在 AstrBot 管理后台进入 **插件 → 输出禁词替换 → 配置**：

- **词语替换（原词 = 替换词）**：每项一条，例如 `折腾 = 搞`，机器人回复的“别折腾了”就会变成“别搞了”。点“添加更多”增加下一条，每条可以填不同的替换词。
- **忽略英文大小写**：默认开启。

等号左右可以有空格，也支持全角等号 `＝`。右边留空表示删掉这个词，例如 `废话 =`。按普通文字匹配，不需要写正则。遇到重叠的词时优先匹配长词，同一轮不会把刚替换出来的词再替换一次。

保存并重载插件后生效。规则初始为空，由你自行添加。旧版的普通禁词、正则和统一替换文本已从配置界面收起，已保存的旧配置仍可生效。

### 含星号整条屏蔽

默认关闭。

开启 **含 * 的回复整条屏蔽** 后，只要 QQ 输出文字含半角 `*`，整条取消发送，不发送提示语。群聊、私聊、复读、主动消息、直接发送工具及自建合并转发均在公共发送入口检查；正常回复另在分段和转图片/语音前检查整条内容，并关闭实时流式输出，避免先发出前半句。直接发送工具会取消含星号的整批消息。

按字符直接匹配，正常加粗、乘法及颜文字里的 `*` 也会被屏蔽。只检查输出的文字组件，不检查图片地址或文件名，也不识别媒体里的字。关闭此开关即可恢复原来的发送方式；总开关也会关闭此规则。

### Markdown 正文拦截

默认关闭。需要 Markdown、代码、数学符号或颜文字时，建议同时保持本项和独立星号屏蔽关闭；群聊人设与草稿保护也应按需选择。

这种做法有时被用于防止分析文本混入回复，但它不是思考识别器。是否启用应依据实际正文泄漏及误拦情况，不按模型品牌一概决定。

开启 **正文含 Markdown 符号时整条屏蔽** 后，正文命中就取消整条 QQ 回复，不发送替代提示语。接口单独返回的隐藏思考文本不参与检查。

默认字符为星号、减号、加号、井号、下划线、反引号、大于号、波浪号、竖线和左右方括号，即配置中的 `* - + # _ > ~ | [ ]` 以及反引号。可以在 **整条屏蔽的 Markdown 字符** 列表中自行增减。

这是字面符号拦截，不解析 Markdown。日期里的减号、数学里的加减号等同样命中。只检查输出正文、语音组件附带的朗读文字和直接发送工具的文字；不检查隐藏思考文本、用户输入、图片 URL、文件名和不可读的思考签名。模型若把分析写进正文，该部分仍按正文检查。

普通 QQ 模型回复关闭流式先发。在主模型每一步响应返回后、执行工具之前检查正文，命中会终止本轮后续模型流程；最终响应钩子、分段前和公共发送入口再检查，覆盖私聊和群聊。直接发送工具的文字按整批检查。

规则不修改模型返回的原始正文或思考对象，也不向 QQ 展示思考。取消后采用框架现有的停止流程，因此本轮运行记录可能被标记为中止。已在更早步骤成功发出的独立消息不会自动撤回，绕过 AstrBot 原始调用 NapCat 的插件仍不在公共发送入口覆盖范围内。

关闭本开关可停用这组字符；原有的独立星号开关仍然生效。禁用插件或重载时会恢复本插件安装的两个入口包装。

## 生效位置

在 QQ 的公共发送入口处理最终文字，覆盖标准回复、报错文字、复读、主动消息和 `send_message_to_user` 的群聊及私聊发送。每次发送只执行一轮规则，避免装饰阶段和发送阶段重复替换。支持同一条消息中相邻的文字段，以及自建合并转发中的文字，保留图片、引用和其他消息组件。

只替换机器人准备发出的文字，不修改收到的用户消息、已保存的聊天记录或已发送消息。已经转成图片、语音或视频的内容，以及按消息 ID 引用的原消息本体，不做 OCR 或识别；分成多次发送的文字按每次发送分别匹配。直接调用 NapCat 原始 API、绕过 AstrBot 公共发送入口的其他插件不在此入口范围内。

本插件不会开启框架的 `also_use_in_response` 整条审核，也不会改变现有输入审核规则。

关闭插件开关可以停止替换；禁用或重载插件时会恢复原发送入口。填写不完整的替换规则会提示所在项及正确格式。
