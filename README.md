# QQ Bot 工具箱 1.0

为 AstrBot + QQ 提供画图、智能回复、观察记录、角色生活、语音和 QQ 空间等功能。一套 WebUI 统一配置，八个功能模块可分别启停。

适用于 AstrBot `>=4.29.1,<4.30.0` 与 NapCat / OneBot v11（aiocqhttp）。其他版本和平台尚未验证。

## 功能

| 功能 | 用途 |
| --- | --- |
| 画图 | 生成、编辑图片，查看任务进度、复用原图补发，管理群友额度；内置奶蛙与大肥鱼参考图。 |
| 复读与智能回复 | 随机复读、艾特判断、围绕群聊话题插话、回复后跟进、私聊合并等待、冷却与休眠。 |
| 模型输入屏蔽 | 在消息进入模型前，按 AstrBot 内容安全词表过滤。 |
| Bot 观察台 | 查看聊天、回复、模型请求、用量、耗时与费用，辅助排查未回复原因。 |
| 真实生活 | 按北京时间提供角色课表与作息，允许在不违反给定经历的前提下补充连贯的虚拟日常。 |
| QQ 随机语音 | 按私聊、群聊各自概率将回复转为语音，使用后台配置的语音服务。 |
| QQ 空间 | 发布文字与可选配图，设置随机间隔、定点任务和每日日记，查看动态、评论与留言。 |
| 输出禁词替换 | 配置词语替换及可选的符号屏蔽、人设与草稿保护。 |

## 开始使用

1. 在 AstrBot 插件管理中从 `https://github.com/lxy005tt-collab/astrbot_plugin_qq_toolbox` 安装，或按 [安装指南](INSTALL.md) 上传 ZIP，启用「QQ Bot 工具箱」。
2. 从 AstrBot 插件详情打开工具箱 WebUI，点击首页大字「新用户必读」查看必要提醒。
3. 点击顶部「功能设置」或模块卡片的「打开设置」，配置需要的功能和模型。
4. 点击「保存并应用」。空间发布另需核对账号、空间连接和发文权限。

界面使用较大的正文与表单字号，关键功能直接显示简短说明，其他字段说明按需展开。空间页可直达随机发布、定点任务、日记和留言；窄屏上的模块按钮会自动换行。

设置中的密钥不回传明文，留空保留已保存值，需要删除时勾选清除。自动刷新不会覆盖未保存内容；其他页面改动配置时会提示冲突。

## 模型配置

每个需要模型的功能均可分别选择后台模型，或独立填写 OpenAI 兼容地址、Key 和模型名。不同功能可用不同服务；默认配置不包含维护者的接口、密钥或专用提供商 ID。

- 文字功能使用 Chat Completions，生图和改图使用 Images API；能聊天的接口不一定支持画图。
- 绘图资料检索额外要求 Responses API 的 `web_search`，可选择按需检索或每次检索。
- 空间配图可复用画图模块，也可单独选模型；使用配图时需启用画图模块。
- 语音合成仅使用后台配置的语音服务，语音表达优化可单独配置文字模型。

生图后台任务会提供进度。同一用户在同一会话有任务未完成时不重复生成；询问进度或补发可使用 `image_task`，补发复用原图。发送接口成功后才记录已发送，QQ 是否显示仍以实际客户端为准。

## 智能回复

普通主动接话在 AstrBot 主动回复概率命中后，再结合上下文判断是否适合参与。可回应某个人，也可沿用当前人格评论大家正在讨论的话题或群体现象；话题插话不自动艾特或引用最后一个人。

群聊艾特判断默认等待 10 秒，将原始艾特与同一用户在窗口内的后续消息一起判断。其他群友只作为背景，默认最多参考 12 条。后续消息不会延长窗口；管理员豁免、冷却与休眠按设置生效。

回复后智能跟进默认观察刚回复的那个人 10 秒，只有对方发了新消息才回顾并判断是否继续回复；没有新消息就不调用判断模型。历史与新消息各最多保留目标用户的 12 条发言，不读取其他群友的历史。

**智能判断、回复后跟进和实际回复均可能消耗模型 token。** 可分别设置模型、开关和等待时间。

## 空间与日记

- 随机发布：每轮从设置的 1～144 小时间隔内抽取，到点由模型决定写什么，配图可选。
- 定点任务：按北京时间每天或指定日期执行，可填写创作要求或直接发布的原文。
- 每日日记：默认关闭，时间默认 23:00。开启后参考当天参与并正常回复过的私聊，以及自己的角色生活，写完发布到空间；不读取群聊。

日记可先生成草稿预览，再手动发布；自动定时会重新回顾当天资料。私聊素材从启用后积累，本机保留近 7 天，日记正文与发布记录单独保存。凌晨 00:00～00:59 写前一天，其余时段写当天；同一天最多发一篇，离线错过不补发，结果未知时先到空间核对。

写作要求区分自己与他人的经历，不公开他人的原话和可识别隐私。角色生活可补充合理日常，但已有的人设、课表、时间地点、经历与约定优先，不能编造工具执行成功。

## 常用命令

`/画图`、`/图生图`、`/修图`、`/绘图额度`、`/奶蛙`、`/大肥鱼`、`/指令`、`/空间帮助`、`/空间计划`、`/定点空间`、`/空间日记`。

输入 `/指令` 查看具体用法。奶蛙与大肥鱼参考图随包提供，也可在画图设置中预览、下载或指定自己的参考图。

## 使用前留意

人设保护、草稿拦截、Markdown 符号屏蔽及独立星号屏蔽默认关闭。它们可能误拦正常的 Markdown、代码与颜文字，应按实际需要开启。群聊人设保护还会关闭群聊流式与思考展示。

观察记录可能包含聊天和请求内容，分享前检查隐私。发布日记、生成文案、检索、生图及语音优化可能产生额外服务用量；群友绘图额度不代替服务商账单限额。
